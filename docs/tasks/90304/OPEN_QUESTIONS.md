# Открытые вопросы — задача #90304

Накопительный канал приёмки. Сюда попадает класс **C вне зон риска**: кейс требует поведения, которого нет ни в постановке, ни в журнале допущений, но цена ошибки не критична. С Шага 5.5 `task-start` сюда же падают второстепенные краевые случаи, отсеянные при генерации вопросов к постановщику.

**Эти строки не блокируют задачу.** Разбираются пачкой раз в неделю, а не по одному в момент разработки — блокирующий канал обязан оставаться узким, иначе постановщик начнёт штамповать «ок» не читая.

Канал — **не свалка**. Повторяющийся вопрос отсюда становится пунктом чек-листа для расширения критериев в следующих задачах: один и тот же вопрос, всплывший трижды, означает, что постановки систематически молчат об этом месте.
