## Что было

Фронт сам считал окна отмены по локальным формулам (ButtonActionMapper.canCancelNewOrNotAccepted / canCancelAccepted + интервалы cancel_order/cancel_task из getUserIntervals). Черновик без услуг кнопку «Отменить» не получал; у принятых кнопка пропадала на date_end, раньше реального окна сервера; протухший флаг мог дать «кнопка есть → 422».

## Что сделано

Видимость кнопки «Отменить» на всех четырёх экранах (список и карточка × Поручение и Задача) переведена на серверный флаг canCancel из ответа API. Черновик без услуг получает кнопку (бэк #89553). Подтверждение в модалке — с перезапросом карточки и guard (окно истекло, пока модалка открыта → снекбар «Время для отмены … истекло», запрос не уходит). Локальный расчёт окон и cancel_-интервалы из сервисов убраны; ветки отмены удалены из ButtonActionMapper (canRepeatCancelled остался). Заявки не тронуты.

Попутно закрыт баг #90258: в карточке Поручения кнопка «Отправить поручение» активна без услуг → клик уводил на страницу ошибки 422; теперь disabled до появления услуг (отдельный коммит e26a1ed в этой ветке).
