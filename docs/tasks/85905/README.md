## Постановка

**Описание (как сейчас работает):**
В разделе «Заявки» кнопка «Отменить заявку» расположена только внутри формы редактирования (под кнопкой «Сохранить заявку»). Для отмены пользователю необходимо: открыть карточку заявки → перейти в режим редактирования → прокрутить страницу вниз → найти кнопку «Отменить заявку».

В то же время, в разделах «Поручения» и «Задачи» кнопка «Отменить» отображается непосредственно на карточке в общем списке и доступна в 1 клик с подтверждением через модальное окно.

**Шаги для проверки текущей реализации:**

1. Авторизоваться под ролью «Супервайзер» или «Менеджер»
2. Перейти в раздел «Заявки» → статус «Новый» или «На рассмотрении»
3. Убедиться, что на карточке заявки в списке отсутствует кнопка «Отменить заявку»
4. Кликнуть на карточку заявки для открытия детальной информации
5. Нажать на иконку редактирования (карандаш)
6. Прокрутить страницу вниз до конца формы
7. Обнаружить кнопку «Отменить заявку» под кнопкой «Сохранить заявку»

**Фактический результат:**
Кнопка «Отменить заявку» находится только внутри формы редактирования заявки, что требует от пользователя выполнения 3-4 дополнительных действий для отмены. Нарушен принцип единообразия интерфейса с разделами «Поручения» и «Задачи». https://skrinshoter.ru/vcHWTZKxqM9

**Ожидаемый результат:**

1. Кнопка «Отменить заявку» отображается **на карточке заявки в общем списке** (в разделе «Заявки»), аналогично разделам «Поручения» и «Задачи» https://skrinshoter.ru/scI7WuGhG3A
2. Кнопка доступна для заявок в статусах «Новый» и «На рассмотрении» в пределах интервала отмены (Дата отправки + 02:00)
3. При нажатии на кнопку появляется **модальное окно подтверждения** с текстом «Отменить заявку?» и кнопками «Нет» / «Да» https://skrinshoter.ru/scHi2OFfyL6
4. После подтверждения заявка переводится в статус «Отменено»
5. После истечения интервала отмены кнопка автоматически скрывается с карточки в списке
6. Единый стандарт расположения кнопок управления во всех разделах («Поручения», «Задачи», «Заявки»)

**В ТЗ внесён Раздел VI.1.8** https://skrinshoter.ru/scIn1JNQRY0
