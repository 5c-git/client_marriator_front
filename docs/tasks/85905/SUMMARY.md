# Задача #85905 — Перенести кнопку «Отменить заявку» из формы редактирования на карточку заявки в общем списке

## Что было

На десктопе кнопка отмены в детальной карточке Заявки, Задачи и Поручения сразу переводила сущность в «Отменено» — без модалки подтверждения (БАГ №1 прогонов QA #3 и #4). Ошибка API отмены открывала страницу ошибки вместо карточки. Карточка Заявки после отмены продолжала показывать старый статус. Отмена и «Повторить» у Задачи на десктопе отправляли `orderId` вместо `taskId`.

## Что сделано

- Кнопка отмены в десктопных карточках Заявки, Задачи и Поручения открывает модалку «Отменить …?» с «Нет» / «Да» — как в мобильных списках. «Нет», Esc и клик вне модалки ничего не меняют.
- На «Да» интервал отмены проверяется повторно: если истёк, запрос не уходит, показывается «Время для отмены … истекло».
- Ошибка API или ответ `success: false` — модалка закрыта, сообщение «Не удалось отменить …», статус прежний, страница ошибки не открывается (401 по-прежнему ведёт на перелогин).
- Пока запрос отмены идёт, кнопка неактивна; сообщение об ошибке не сбрасывает это состояние посреди повторного запроса.
- Карточка Заявки после отмены сразу показывает «Отменено».
- Задача: отмена и «Повторить» отправляют `taskId`.
- Условия показа кнопок (статусы, интервалы) и мобильные списки не менялись.
