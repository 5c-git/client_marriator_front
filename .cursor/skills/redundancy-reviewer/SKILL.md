# Агент: ревью избыточного кода

Роль: **контролёр**, не автор фич. Цель — сократить diff и убрать код, который не меняет поведение.

## Когда запускать

- После написания или рефакторинга `*.service.ts`, loaders/actions, DI-модулей.
- Перед сообщением пользователю «готово».
- По явной просьбе пользователя.

## Алгоритм (строго по порядку)

### 1. Собрать контекст

- `git diff` затронутых файлов (или прочитать изменённые файлы).
- Найти **единую точку ответственности** для каждой операции (guard, auth, map, API).

### 2. Чеклист избыточности

| # | Вопрос | Действие при «да» |
|---|--------|-------------------|
| A | Проверка повторяет метод, который уже throws/return narrow type? | Удалить внешнюю проверку |
| B | Ветка недостижима по TypeScript? | Удалить |
| C | Переменная используется один раз без side effects? | Инлайн |
| D | Новый файл дублирует соседний `*.service.ts` / `shared/`? | Объединить или переиспользовать |
| E | Два формата ошибки для одного случая (`Error` vs `Response`)? | Оставить один (в проекте — `AppService.getToken`) |
| F | DI-токен/биндинг без новой зависимости? | Не добавлять |
| G | Комментарий/лог только «для отладки» без запроса? | Не добавлять |

### 3. Проектные якоря (читать при сомнении)

- `app/shared/container/container.service.ts` — `getToken(): string`, уже валидирует токен.
- Эталон сервиса: `app/routes/profile/settings/settings.service.ts`.
- Рефакторинг роутов: `layout.tsx` + `*.service.ts` + `*.module.ts` + `_views/`, без лишних слоёв.

### 4. Отчёт пользователю

Только если нашёл проблемы:

```markdown
## Ревью избыточности

### Убрать
- `path:line` — причина (1 предложение)

### Оставить как есть
- (если всё чисто: «Избыточности в diff не найдено»)
```

Не предлагать рефакторинг несвязанных файлов.

## Запрещено агенту

- Добавлять «защитные» проверки без нового требования.
- Расширять scope «заодно улучшим».
- Создавать helper из 1–2 строк без повторного использования.

## Автоисправление

Если избыточность очевидна и в scope текущей задачи — **исправить сразу**, не только отчитаться.
